# MetaTrest — Evolution CMS workspace

Рабочий каталог: `C:\OSPanel_new\home\metatrest.local`.
Корень сайта: `public/`. Git находится в корне проекта, не внутри `public/`.

## Локальный просмотр

- `http://metatrest.local/` — установленная Evolution CMS.
- `http://metatrest.local/index.php` — прямой вход в CMS.
- `http://metatrest.local/manager/` — страница входа в административную часть.
- `http://metatrest.local/index.html` — статическая главная, включая мобильную версию.
- `http://metatrest.local/projects.html` — статические проекты.
- `http://metatrest.local/services.html` — статические услуги.

В `public/.htaccess` задан `DirectoryIndex index.php index.html`: статическая главная
не перехватывает корневой URL CMS. В локальной БД подключены три страницы и DLMenu.
Templates и Chunks работают из MySQL. Их точные файловые копии находятся в `cms-src/`.
Ресурсы и TV автоматически не устанавливаются: клонирование репозитория не переносит
локальную БД. Схема полей и порядок редактирования описаны в `cms-src/README.md`.
Логотип статических страниц ведёт на `index.html`; корневой URL остаётся за CMS.

## Общие HTML-блоки

Редактировать Header, Footer и мобильное меню в `public/index.html`, форму — в `public/projects.html`.
Кнопки мобильного меню синхронизируются с кнопками Hero главной страницы.
Из корня репозитория выполнить:

```shell
python scripts/sync_shared.py
```

Скрипт синхронизирует общие блоки трёх статических страниц. Сборщик не требуется.
Мобильные версии главной, проектов и услуг до 1024px включительно находятся
в `public/assets/css/mobile.css`. Оригиналы фотографий проектов из Figma переиспользуются на всех ширинах.
Фильтры проектов пока отображают подтверждённое статическое состояние. Отправка формы
и переходы на отсутствующие детальные страницы ещё не подключены.

## Что хранится в Git

Вёрстка MetaTrest, исходные изображения и SVG, CSS/JS, скрипт синхронизации,
`public/index.php`, `.htaccess`, `composer.json`, лицензия Evolution и доступные
исходники/защитные файлы внутри `public/assets/`.
Существующая установка: Evolution CE 1.4.37, PHP 8.3. Ядро не обновлялось.

**Репозиторий не является полностью разворачиваемой копией CMS.**
`public/manager/` и Composer-зависимости исключены по условиям проекта.
После клонирования нужно отдельно установить/восстановить административную часть
и зависимости из совместимого дистрибутива Evolution CE 1.4.37, подготовить локальные
настройки OSPanel, подключение к БД и саму БД. Выполнение `composer install` только
по имеющемуся composer.json не следует считать полным восстановлением установки.
Пароли, `.osp/`, кеши, SQL-дампы, резервные копии и пользовательские загрузки не публикуются.
CSS, JS, `assets/img/` и `assets/svg/` не исключаются.

## Локальные шрифты

Право на публикацию пробных TT Commons Classic Trl не подтверждено.
`public/assets/fonts/` остаётся локально и полностью исключён из Git.
Для точного просмотра после клонирования добавить законно полученные файлы:

- `TT_Commons_Classic_Trial_Regular.woff2` (400);
- `TT_Commons_Classic_Trial_Medium.woff2` (500).

CSS уже подключает их по этим именам. При переходе на лицензированную веб-версию
нужно использовать предоставленные правообладателем файлы и условия лицензии.

## Резервная копия и границы миграции

Перед переносом сохранены файлы CMS и `.osp/` в локальном `backups/pre-migration-*/`:
архив `evolution-files.zip` и контрольные суммы `sha256-before.json`.
Этот каталог находится вне публичного сайта и исключён из Git.
Старая рабочая копия `C:\OSPanel\domains\metrotrest` сохранена без изменений.
База данных, системные файлы CMS и настройки OSPanel не мигрировались и не обновлялись;
единственное изменение конфигурации сайта — указанный приоритет index.php в .htaccess.
